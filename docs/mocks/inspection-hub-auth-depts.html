Password management (recommended)
  • Local accounts: unique work email + hashed password (you already store passwordHash).
  • Create user: Admin sets email + role + dept access; system generates a random temp password; show/copy once; force change on first login.
  • Reset: Admin “Reset password” → new random temp; user changes on next sign-in.
  • Self-service later: “Forgot password” via email link (optional for UAT).
  • Enterprise path: keep Entra/SSO ready (IdentityProvider.entra) for production; local passwords for UAT / contractors.
